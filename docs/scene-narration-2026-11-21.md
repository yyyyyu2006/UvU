# 私聊线下场景与旁白

2026-11-21。首版实现范围为私聊、同聊天连续记录；先交 test，用户确认后才 main。

## 使用

1. 私聊底部“+”功能区，左右滑动找到“线下场景”。开启“旁白模式”，填写场景后保存。
2. 正常发送文字。需要把自己的消息改为动作时，长按消息→原“编辑消息”面板→勾选“改为旁白”→保存；取消勾选可恢复气泡，正文、时间和原编辑功能保留。
3. 角色对白沿用原气泡；动作和环境以灰色、斜体、11px居中穿插，不显示来源标签。顶部“回到线上”恢复原线上请求，已保存旁白仍然保留。
4. 格式错误或生成中断时，从“线下场景”或“回复草稿”查看并复制已收到的原文；不会自动调用收费接口修复格式。
5. 使用说明只在右上角“?”中显示；“返回设置”保留未保存字段，重新打开默认显示设置页。

本日后续的缺陷复现、修复和1900/上下文复核见 [旁白首版复核](scene-review-2026-11-21.md)。

## 实现与兼容

- 每轮角色正文一个 history 对象，内部有序 blocks 带稳定片段ID。作者、消息ID、原时间和引用归属保留；长按编辑/引用定位片段，删除和重新生成仍按原父回合处理。
- content/parts 是 blocks 的确定性文字投影。转换和编辑会使旧摘要来源失效，不自动写入永久记忆。可用原消息源码调试整份 scene 结构，未知版本或损坏字段不覆盖原文。
- 场景开启时使用当前聊天主API和单次结构化回复，复用本轮世界书计划；不用副API拼接，所选思考预设与预填按当前开关接入，冲突的线上输出规则由线下协议替代。旁白文字中的图片、礼物、状态或HTML仅显示文字。
- 关闭/旧数据缺字段时保留1900请求路径。原版/第三方气泡的直接子节点结构保留；新CSS只作用于旁白和新控件。音乐、语音、ID卡与已发卡片未重设计。
- 设置和故障原文归对应角色/存档；切换取消生成，迟到响应不入正式历史。新空白存档不继承旧场景。分类备份与完整记录导入校验新字段。
- 本版不含群聊、自动配音/生图、后台自动剧情推进。通话和酒馆有效线下占用继续阻止剧情请求。实际收到的思考单独关联本轮，无思考的回复不借用前轮内容。

## 线下提示词与思考预设（2026-11-21更新）

当前线下版由1900原私聊提示词组装函数派生：沿用角色/全局选择的uwu或tt版本、双方人设、状态、世界书顺序、允许记忆与人物互动规则。仅在场景开启时替换纯线上关系、禁止动作、线上消息指令/状态栏及短消息格式；不强凑线上消息数量。tt保留原历史占位符处理。旧独立精简剧情提示词已被替换；关闭模式的原提示词和完整请求仍须通过1900对照。

说出口的话只进dialogue，动作、神态和必要环境只进narration；不要求每句对白配动作，不替用户补行动或心理，不自动改写用户输入。旁白UI与原气泡/第三方美化不调整。场景时间有填写时优先于设备时间，双语仅作用于对白。

生成的旁白避开“嘴角一勾”“邪魅的笑”“薄唇轻启”等霸总式油腻套话，也不换近义词沿用同一套路；普通互动不一律解释成挑逗、占有或审视猎物。用符合人物与场景的具体动作表达，允许自然微笑、停顿和视线变化，不强凑动作、不削平性格。此为生成提示约束，不是生成后删词过滤；用户输入和已有历史保留，实际文风仍需真实模型试用。

思考预设按“角色专属→全局→default”选择，仅使用已启用条目。OpenAI兼容与Gemini的场景请求均接入所选预设、原触发器及可关闭的预填；末尾加线下输出约束，避免预设里的旧消息格式污染JSON。线上Gemini请求保持原行为，不借本次改动增加思考步骤。只显示接口实际返回并保存的思考；预填消耗的开头仅在该请求确实启用预填时恢复，JSON正文中的结束标签保持原文。

请求生成期间变更提示词版本、双语或思考设置/内容会令旧结果过期，原文按既有草稿路径保留。JSON校验、停止/格式失败、同聊天历史范围、世界书单次激活和备份协议保持原约束。具体自然度、自定义预设冲突和真实模型JSON稳定性仍需用户在test试用；模拟接口检查不等于真实模型效果验收。
