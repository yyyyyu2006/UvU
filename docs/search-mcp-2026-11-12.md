# 搜索 MCP 接入与回复按钮（2026-11-12）

## 本次实现

- AI 回复键在生成期间变为同位置的小停止方块，再次点击取消当前角色、当前存档的请求。没有新增第二个浮在按钮上的停止键。
- 保留原回复图标 DOM 和自定义图标入口；结束或取消后恢复。输入草稿时仍能停止，不清空草稿。
- MCP 添加服务的“服务模板”新增“Exa 网页搜索”：自动填入官方地址 `https://mcp.exa.ai/mcp`、无需令牌、兼容协议 `2025-03-26`。
- 模板不自动开启服务、总开关、工具或角色权限，不发送请求，不内置共享密钥。

## 怎么使用

1. 打开 API 设置 → MCP 服务，开启总开关，添加服务并选择“Exa 网页搜索”。
2. 勾选启用此服务并保存，选择该服务，点击“测试 / 刷新工具”。匿名服务有限流；有自己的 Exa 密钥时可选 Bearer 认证。
3. 检查 `web_search_exa`、`web_fetch_exa` 等工具，按实际用途启用并确认只读，保存。工具名单和必填参数以实时发现结果为准，不写死旧版参数。
4. 在角色授权里选择需要联网的角色，勾选允许外部资料及对应工具；需要自动搜索时再开启自动判断。
5. 配置独立工具判断 API。它判断近期消息是否需要搜索，再调用已授权工具；成功资料作为外部参考提供给聊天模型，仍由原聊天模型回复。该判断 API 会增加模型调用。

搜索词和工具参数发送给所选服务，独立判断 API 接收设置范围内的近期清洗消息与已授权工具定义。不开启时不介入普通聊天。搜索失败沿用原本的普通回复回退，不能把失败当作已查证。

## 查阅的官方开源实现

| 项目 | 参考内容 | 当前选择 |
| --- | --- | --- |
| [Exa MCP](https://github.com/exa-labs/exa-mcp-server) | 托管 MCP、匿名限流搜索、网页读取、Bearer、按 schema 调用 | 首个内置地址模板；无需用户自建搜索服务器 |
| [Tavily MCP](https://github.com/tavily-ai/tavily-mcp) | 搜索和网页抽取、远程 MCP、Bearer 密钥 | 可用现有自定义服务接入；不内置公共密钥 |
| [Brave Search MCP](https://github.com/brave/brave-search-mcp-server) | 分类搜索、HTTP/stdio 两种运行方式、API 密钥 | 浏览器需用 HTTP 服务；stdio 不能直接在 Pages 中运行 |
| [SearXNG](https://github.com/searxng/searxng) | 自托管聚合搜索 | 它本身不是本项目可直接调用的 MCP 接口；需额外适配和部署，不作为免配置来源 |

上述资料通过 GitHub 官方仓库 API 读取 README 核对；Exa/Tavily/Brave 仓库返回 MIT，SearXNG 返回 AGPL-3.0。本次未复制这些项目代码或加入依赖。

## 验证边界

- 浏览器隔离数据：同按钮开始/取消、320/390px 可点、草稿保留、图标保留、不同角色请求分别取消。
- 本地跨域 MCP 模拟服务：模板填写且不联网、不自动授权，以及原有发现、授权、调用、自动判断、取消等检查。
- Exa 真实接口通过 PowerShell 成功返回初始化结果和 `web_search_exa`、`web_fetch_exa` 工具列表，并返回允许跨域的响应头。协议选择 2025 系列避免新协议额外请求头与其跨域白名单不匹配。
- 本机 Chrome 的真实 Exa 连接超时；后续请求也出现连接错误。没有完成真实搜索调用，不能宣称所有玩家免配置即可使用。可能受本机网络、服务或浏览器环境影响，原因尚未确定。未使用真实账号、付费搜索或玩家存档验证。
- 公共匿名服务的额度、长期可用性和各地网络访问不能保证；需要在玩家实际网络中完成搜索和资料进入回复的最终验收。
