# 角色备忘录

在原有模拟手机便签之外，增加可纠错、有原文依据的私人备忘录。默认关闭；不改基础提示词和历史顺序。

## 已实现范围

- 每角色、当前存档、用户人设独立，主开关／自主记录／用于对话分开控制。
- 后台增量整理，阈值2—60，单批30，最近60条，五分钟冷却，45秒超时，失败手动重试。
- 用户与角色自身计划分开；原文证据、时间和消息指纹可检查。转述、非明确第一人称或不确定内容必须审核。
- 事实、角色口吻便签、类别、审核状态、置顶、锁定、到期和完成。
- 添加、编辑、搜索、筛选、批准、更正、来源查看、删除撤销、不再记录和取消忽略。
- 相关性与字数上限选择，最多6条，去除已有提示词重复内容。
- 选中记录导出JSON或显式加入日记；日记使用开关仍由原记忆面板控制。
- 既有完整备份可保存此纯数据结构；PNG角色卡过滤私人备忘录。

## 边界

暂不自动采集酒馆、动态、文件等外部来源，不自动修改人设／世界书，不自动联动日程，不强制建立新的向量索引。现有模拟便签保留独立入口。自动身份识别依赖模型加保守规则，不宣称所有表达都能准确自动确认。

## 弹窗

二改弹层使用原生白色、24px圆角和外边距，头尾固定、正文内部滚动。自动总结批量楼层区放在同一滚动表单内，避免挤占设置。保护音乐、已发送卡片、ID卡图案与1900美化。
