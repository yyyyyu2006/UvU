# 新增面板的卡片布局与图标

按用户给定的参考图实现移动端单列卡片，不复制桌面多列布局。白色卡片搭配浅灰画布；24px 外层圆角、20px 内卡、8/16/24px 间距，主要操作使用胶囊按钮。只作用于二改新增面板。

## 实现

1. 文件分享直接锁定打开时的私聊对象与存档，移除接收对象下拉和首角色兜底。未选文件只展示选择卡片；读取后展示文件名、可滚动正文和发送操作。原件下载和格式导出收进次级菜单，说明留在底部。
2. 从 Lucide 0.468.0 的官方 SVG 选取本地子集，保留许可证和来源。不加载 CDN，不替换原版聊天控件；通过明确限定的新面板范围装饰操作按钮，保留文字和可访问名称。
3. MCP 按开启、服务、工具、角色授权、高级设置、帮助排列；好友关系按当前状态、我的操作、角色行为、恢复规则排列；环境设置先位置后高级服务。其他新增面板保留已有合理顺序，统一间距与工具条。
4. 不修改提示词、回复组装、存储结构或原版美化文件。

## 验证

- 文件面板空态与已载入态、无接收角色选择器、切换当前聊天后仍向原角色发送；无有效私聊不打开面板。
- 320/390/768px 的实际页面截图、内部滚动、无横向溢出；新图标不装饰原版按钮。
- 文件导入/编辑副本/原件下载等现有浏览器回归，MCP 与关系设置布局回归，1900 兼容测试与全套单元测试。
- 检查换行、提交差异并推送 main。

## 面板顺序复核

- 文件：选择 → 预览编辑 → 下载与帮助 → 发送。
- 自动总结：开关 → 路由 → 小总结 → 大总结 → 自定义规则 → 保存；批量指定范围保持独立。
- 向量与记忆管理：配置 → 检索参数；管理页先筛选与记忆列表，再限额和诊断。
- 酒馆：连接 → 角色与消息范围 → 交接 → 可见的剧情审核 → 教程，保持此顺序。
- MCP：开关 → 连接服务 → 选择工具 → 角色授权 → 自动判断与日志 → 导入导出与教程。
- 语音：接口与默认音色 → 速度音调 → 可选导演 → 试听保存，保持此顺序。
- 位置日历：开关 → 我的所在地 → 异地角色 → 高级服务 → 保存。
- 好友关系：当前状态 → 我的操作 → 角色状态 → 自主判断 → 恢复。
- 展开编辑：查找替换 → 正文；表情导入：预览勾选 → 分类与导入，保持已有流程。

文件面板实际应用回归覆盖原件下载、目标聊天锁定、存档失效、空态、编辑副本和 320/390/768px；420px 高度模拟软键盘可用区，确认内部滚动。真实跨域 MCP 测试覆盖服务编辑、分页发现、工具/角色授权、调用、写入确认。图标单独验证文字与无障碍名称、点击回调、动态重建及不影响原版按钮。全套 636 项单元测试通过。
