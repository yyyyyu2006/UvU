# 动态副 API 与重要日同步对象

2026-11-16，基于 test 3575c66。用户授权动态使用副 API、说明移到右上问号、重要日明确同步给谁看。

## 实现与兼容

- 动态评论、人物提取、动态草稿和摘要严格使用已启用且完整的副 API。缺地址、密钥、模型或模块未就绪时明确提示，不回退主 API。普通聊天请求路径不变。
- 动态设置正文移除使用说明，复用右上问号和现有说明弹窗；保留本次互动状态、停止按钮和设置。关闭帮助恢复焦点。
- 重要日开启聊天引用后用原生复选框选择角色和存档。我的重要日可选多个角色当前存档；角色重要日维持原本隔离，只允许所属角色存档。已有非当前存档授权可见且可取消。
- 记录保存 shareTargets，实际上下文同时检查单条许可、角色与存档目标、对应角色引用开关。默认不共享；备注、地点、原始日期不传入聊天。关闭引用清空所选目标，原撤销流程保留。
- 无明确目标的旧记录保留日历显示，但需重新选人后才进入聊天。新版读取 v1/v2；保存重要日升级 v3，使旧客户端拒绝读取，避免旧逻辑忽略目标限制。编辑器提供升级前备份，完整新版备份优先；兼容 v1 单年导出仍会丢失重要日规则与权限，不能代替完整备份。
- 保存时检查对象身份，选人后切存档不会串写新目标；校验覆盖非法/重复/超限目标，JSON/EE 和日历导入保留目标限制。
