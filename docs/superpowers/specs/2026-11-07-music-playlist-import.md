# 音乐歌单导入

在资料库的播放列表页增加“导入歌单”。支持网易云和 QQ 音乐的完整歌单链接、分享文案里的完整链接，以及选定平台后的数字歌单 ID。短链接明确提示在官方平台打开后复制完整歌单链接，不访问任意用户网址。

通过已有音乐网关读取分页歌曲，先预览、修改名称，再确认一次性保存到本地资料库。默认名称为平台和歌单 ID；账号已有歌单沿用名称。无需下载音频。公共源不新增未经确认的歌单接口。

最多导入 1000 首，超出时在预览中明确显示截取提示；重复歌曲去重，保留顺序。预览失败、取消或更改网关不保存，保存失败回滚。不同导入会话隔离，关闭面板立即取消请求。账号歌单页面也提供同一导入流程。

只改音乐模块与教程，不改 1900 的提示词、回复流程、美化以及音乐卡片发送目标。沿用已批准的音乐 UI；按钮简洁，操作说明按需显示。保留现有备份结构，不保存原始分享链接、平台凭据或音频地址。
