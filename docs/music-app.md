# 音乐 App 使用说明

桌面新增独立的「音乐」图标；「酒馆」入口保留。私聊的加号面板也能打开音乐。

## 不连接账号也能使用

在资料库点「导入音乐」或「喜欢的歌」旁的加号，选择手机中的音频。每个文件最多 30 MB，支持浏览器可解码的 MP3、AAC/M4A、WAV、OGG、WebM、FLAC。支持的容器不代表设备支持所有编码。音乐单独存入本机 IndexedDB；刷新不自动播放。

歌曲的「更多」菜单可收藏、加入歌单、排到下一首、分享或邀请一起听。本地歌曲可从这里删除，清理音频、资料库、歌单和队列；已发送的卡片仍保留文字资料。

底部迷你播放器可暂停、下一首、展开。展开后可拖动进度、切换顺序/随机/单曲循环、看歌词与队列、设定 15/30/60 分钟定时关闭。MiniMax 语音播放时会暂停音乐，结束或手动暂停语音后尝试恢复；期间手动操作了音乐则尊重该操作。

## 网易云和 QQ 音乐

这两个平台通过独立的音乐服务连接。GitHub Pages 只能放前端文件，不能运行平台登录服务。当前仓库提供服务代码，**没有替你部署可供所有玩家登录的公网服务**。

1. 在支持 Node.js 22 或更高版本的电脑/服务器上取得 UvU 仓库，进入仓库根目录。
2. 执行 `node services/music-gateway/setup.mjs`。这会下载固定版本的平台适配引擎到被 Git 忽略的 `.runtime`，不会将玩家账号文件提交到仓库。
3. 复制 `services/music-gateway/.env.example` 为同目录 `.env`，设置 `MUSIC_ORIGINS` 为实际网页来源，例如 `https://yyyyyu2006.github.io`。来源不包含 `/UvU/` 路径。
4. 执行：

```sh
node --env-file=services/music-gateway/.env services/music-gateway/start.mjs
```

5. 线上网页请按 [服务部署说明](../services/music-gateway/README.md) 配置 HTTPS。网页与服务在同一台电脑时可测试 `http://127.0.0.1:8787`；手机上的 `127.0.0.1` 是手机自身，不能指向电脑。
6. 打开「音乐」右上角的账号按钮，填写服务地址并连接。
7. 选择网易云或 QQ 音乐「扫码登录」，用相应官方 App 授权。二维码会过期；退出登录或新建二维码会作废旧授权流程。同机操作可保存/截取二维码后使用官方 App 的相册识别，是否支持以平台为准。
8. 登录后可以读取账号歌单；搜索可选择全部、网易云、QQ 音乐。一方出错会保留另一方结果。平台会员、地区、版权和试听限制仍然生效，没有解锁会员功能。

默认服务会话在内存保留 24 小时，重启后需重新登录。「记住此设备」需要服务配置加密 vault；新会话最长 7 天。修改已有会话的选项只改变浏览器是否保留访问凭据，不延长服务端有效期。具体配置见服务 README。

平台接口可能变化，真机扫码、账号权益与移动端后台音频仍需实测。当前自动化验证使用本地接口和音频夹具，没有使用真实账号或收费接口。

## 分享和一起听

从私聊加号进入音乐后，分享固定发给该角色和进入时的存档；存档已切换会提示重新选择。从桌面进入，则在发送时选择角色。

分享面板可以「读取歌词」，保留或编辑需要的片段，最多 2000 字符。char 接收歌名、歌手、专辑、时长与附上的歌词；不会直接听到音频。

「一起听」发出一条邀请。点击原有回复按钮后，char 可根据角色设定接受或婉拒；没有邀请时不加入音乐行动规则。接受后才尝试本机播放，浏览器拦截时需点击卡片的播放按钮。卡片可以撤销邀请或结束一起听，邀请 30 分钟未处理会过期。

这是与 AI 角色的聊天互动，不是另一台真实设备的同步播放服务。切换其他歌曲或停止播放会结束当前播放绑定；暂停会保留绑定。分享本地音乐只分享资料，另一台设备不会收到音频文件。

## 备份和隐私

音乐设置和资料库随「基础设置」分类备份，聊天卡片随聊天记录备份。备份不含平台 cookie、音乐服务访问令牌、临时播放地址或音频文件。恢复到其他设备后，本地歌曲需重新导入；原有资料和卡片仍可查看。备份不会复制账号登录状态。

音频持续后台播放和锁屏媒体控制由系统、浏览器与 PWA 的实际支持决定。浏览器关闭后网页不会继续执行 AI 请求。
