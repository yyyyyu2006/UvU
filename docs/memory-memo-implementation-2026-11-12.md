## 20项落实对照

| 编号 | 实际实现 | 入口／限制 |
| --- | --- | --- |
| 1 事实结构 | 在旧fact/content/subject上增加entityId、属性、取值、肯否、表达类型；保留原话和指纹。 | 编辑 → 事实与隐私。自动提取仍经过原证据校验；不会为旧记录强制推断属性。 |
| 2 有效时间 | recordedAt与validFrom/validTo分开；当前召回检查有效期，更正旧事实时关闭其有效期。 | 编辑有效时段；设置 → 主题与时间，可查询指定时点。没有凭语句自动推断任意历史日期。 |
| 3 审核解释 | 记录reviewReason、修改前版本，详情展示原话、待审原因及修订。 | 查看 → 历史与关联。仅保留最近10次修订。 |
| 4 回收站 | 删除项跨刷新保留，支持恢复和彻底删除；重复ID或容量不足不覆盖恢复。 | 设置 → 回收站。最近50条、逻辑期限30天；到期项立即不显示，后续备忘录写入时才落盘清理。不是旧数据库、云备份的取证级擦除。 |
| 5 关联失效 | 删除／暂停前展示关联日记、合并记录数量；停用、本地查看、到期、原话变化或事实改写后，关联派生记录不可召回。 | 确认窗口及详情。独立复制的日记不由memo来源标识控制；索引可在下次校验／重建时清理。 |
| 6 操作语义 | 删除不加屏蔽；忽略保留屏蔽规则；暂停与更正独立；忽略后恢复会撤回该次屏蔽。 | 彻底删除忽略项时移除正文和修订，保留无正文的屏蔽哈希；“已忽略的事情”可单独恢复允许记录。旧备份不受影响。 |
| 7 缓存语义召回 | 独立开关＋手动构建；复用用户向量配置，query/document任务类型区分；每批请求前后重新校验来源。 | 设置 → 整理与隐私。最多50条、1小时页内缓存；无缓存、消息／事实／配置变化时回退原文字匹配；超时45秒，聊天召回不发向量请求。 |
| 8 排序对照 | 备忘录提供可选RRF与相同事实只选一条；日记检索只额外计算加权/RRF诊断顺序。 | 默认原排序。日记实际排序、命中门槛与结果不改；对照只供查看，不宣称实测效果更好。 |
| 9 跨来源事实 | 对备忘录和日记片段分组，检查人物、肯否和时段；未知人物的完全相同文本标记待核对。 | 设置 → 跨来源事实对照。最近200条备忘录、100篇日记各前5片段；只建议，不自动合并，不保证识别所有同义表达。 |
| 10 总结保真 | 日记来源详情提供事件／稳定事实／临时计划标签，并检查原话日期、承诺和待办是否逐字保留。 | 记忆详情 → 查看原文 → 总结保真对照。是文字差异提醒，不是模型语义准确性证明；沿用既有总结审核和原文保存。 |
| 11 预算预览 | 沿用原备忘录字数与条数限制，补选中ID、原因、字符量和粗略token；并列显示上一轮向量诊断字数。 | 备忘录设置 → 本轮可用记忆。不同时间的预览与实际请求明确区分；不改变原聊天／提示词长度，不新增跨模块统一截断器。 |
| 12 主题与时间 | 可编辑主题和关联人物；按主题、人物、事实有效时点查询。 | 设置 → 主题与时间。关系字段由用户修正，查询不产生新事实。 |
| 13 可恢复任务 | 调用前保存任务输入ID和指纹，失败保存状态；重新打开显示未完成，由用户重试／丢弃。 | 重试固定读取失败时的原输入，即使新增61条聊天也不会换批；原话变化后拒绝重试。刷新不自动重跑付费接口。 |
| 14 原子批审 | 选当前可见页、取消选择；确认／暂停／删除先预览归属和数量；批量主题显示前后差异。 | 每条快照均检查后才一次保存；冲突、过期或来源失效不能批量确认，保存失败回滚。 |
| 15 隐私排除 | 排除主题在提取、备忘录召回、向量提示／缓存前过滤；仅本地查看记录和相关来源不进入备忘录提取请求。 | 设置 → 整理与隐私、编辑 → 事实与隐私。限制新增记忆资料通道；原版聊天发送历史仍按原设置，手动分享原话是独立操作。 |
| 16 统一浏览 | 记忆来源增加备忘录；跨来源搜索可找到尚未复制进日记的备忘录，直接读取原记录。 | 记忆 → 备忘录；状态显示待审／可用／已停用并检查开关、来源、时间与隐私。支持分页、分类和记录日期，不另复制一份数据。 |
| 17 合成回归 | 增加中文明确陈述、否定、引用、转述、假设、过去与反讽样例；覆盖来源删除、切档、重试和并发写入。 | mock接口验证规则、请求次数和失败行为；不是实际外部模型的提取率或召回率基准。 |
| 18 局部反馈 | 有用／不相关，保存本地ID、入选ID和原因，不存反馈正文；可清除统计。 | 查看 → 历史与关联；设置 → 清除本地反馈统计。最近100项，不调用API、不训练模型或直接改变排序。 |
| 19 关系查看 | 详情展示人物→事实→原楼层／关联日记及主题人物字段。 | 本地只读关系查看，字段在编辑里修改；没有多跳推理或图数据库。 |
| 20 外部通道 | 已授权MCP工具结果可编辑后存为待审备忘录；核验真实结果、作用域、授权、有效期和当前角色。 | MCP工具 → 调用 → 存为待审备忘录，400字以内。外部来源单独标记，确认后才可召回；未新增Mem0/LangMem专用客户端、账号或后台部署。 |
