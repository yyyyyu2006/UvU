# 私聊线下场景与旁白

2026-11-21。首版实现范围为私聊、同聊天连续记录；先交 test，用户确认后才 main。

## 使用

1. 私聊底部“+”功能区，左右滑动找到“线下场景”。开启“旁白模式”，填写场景后保存。
2. 正常发送文字。需要把自己的消息改为动作时，长按消息→原“编辑消息”面板→勾选“改为旁白”→保存；取消勾选可恢复气泡，正文、时间和原编辑功能保留。
3. 角色对白沿用原气泡；动作和环境以灰色、斜体、11px居中穿插，不显示来源标签。顶部“回到线上”恢复原线上请求，已保存旁白仍然保留。
4. 格式错误或生成中断时，从“线下场景”或“回复草稿”查看并复制已收到的原文；不会自动调用收费接口修复格式。

## 实现与兼容

- 每轮角色正文一个 history 对象，内部有序 blocks 带稳定片段ID。作者、消息ID、原时间和引用归属保留；长按编辑/引用定位片段，删除和重新生成仍按原父回合处理。
- content/parts 是 blocks 的确定性文字投影。转换和编辑会使旧摘要来源失效，不自动写入永久记忆。可用原消息源码调试整份 scene 结构，未知版本或损坏字段不覆盖原文。
- 场景开启时使用当前聊天主API和单次结构化回复，复用本轮世界书计划；不用副API拼接，不叠加线上冲突规则、旧CoT预填或软件执行指令。旁白文字中的图片、礼物、状态或HTML仅显示文字。
- 关闭/旧数据缺字段时保留1900请求路径。原版/第三方气泡的直接子节点结构保留；新CSS只作用于旁白和新控件。音乐、语音、ID卡与已发卡片未重设计。
- 设置和故障原文归对应角色/存档；切换取消生成，迟到响应不入正式历史。新空白存档不继承旧场景。分类备份与完整记录导入校验新字段。
- 本版不含群聊、自动配音/生图、后台自动剧情推进。通话和酒馆有效线下占用继续阻止剧情请求。实际收到的思考单独关联本轮，无思考的回复不借用前轮内容。
