# 白色默认主页

2026-11-19，用户确认第五稿的错落布局并要求白色底。本批先交 test，尚未取得新布局的 main 发布确认。

- 第一页：顶部时间/头像 4×2、INS 对话 2×2；404、音乐、阅读器、酒馆四个应用。
- 第二页：拍立得左上、方形图文右下；世界书/api/自定义在右上，小组件/壁纸/教程/控制台在左下。保留原三个固定底栏入口。
- 组件图片、短句仍用原有组件编辑功能。复制内置模板并使用独立 ID，不改原版模板及用户已经保存的组件。时间随本地时间更新。
- 新数据库默认使用新版；有任何已存设置、角色、群聊、世界书、表情或旧存储迁移的数据库不会自动重排。
- 已有用户可从「个性化设置 → 管理主页预设 → 使用白色默认布局」预览并主动应用。保留自定义图标、字体、全局 CSS、原组件库及非主页数据；替换分页、壁纸及桌面组件。成功后可在同一页面撤销一次，本次撤销状态不跨刷新。
- 仍可长按排序。进入编辑时释放预设格位；用户改变顺序后沿用原流式排序，刷新保留新顺序，不强行恢复预设位置。默认组件尺寸保留。

## 实施与回退

`home_default_layout.js` 定义默认配置，`loadData()` 仅在确实空数据时采用。`ui.js` 仅增加局部布局装饰与编辑释放入口。`home_default_layout.css` 只匹配选择了默认组件的主页；白色底通过现有壁纸字段保存，不全局覆盖个人壁纸。

使用现有主页预设的白名单、原子保存、模板冲突重命名和撤销流程，没有引入数据库字段或版本迁移。导入导出可往返该布局。已有用户的字体及 CSS 保留，可能继续影响显示；不以恢复默认布局为理由清空其美化。撤销可恢复更换前的分页、壁纸、组件和图标；应用失败由原事务保持旧配置。
