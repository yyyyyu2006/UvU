# 独立旁白提示词融合实施记录

2026-11-21，Asia/Shanghai。用户授权实施已列清单，并明确保护线上两套原提示词、复制到旁白后修改、本批直接推main。此前“先列清单/不推送”已被本次明确授权取代；后续批次仍按各自授权处理。

## 用户可见变化

- 旁白不再默认双方面对面。异地开关独立读取，天气及AI环境感知关闭仍生效；未开异地不等于同场。长期异地与当前临时见面分别承接。
- 面对面承接地点、位置、物件与可感知信息；异地区分文字、语音、视频，只写角色自己一侧，不无依据地跨屏接触、读取远端表情或代用户接听。用户私下旁白可供读者了解，但不自动成为角色知识。
- 区分事实、尝试、愿望、假设和场外修正；不代写用户反应/同意/决定，拒绝和纠正不改成撒娇或自动和好。模型错误历史不自证为真；不自动删除、清洗用户历史或记忆。
- 根据白噪音v4.0与1900原版覆盖对照，补充情绪连续、人物有限能力、关系推进/修复、生活取舍、NPC知情、去戏剧化、合理照顾、去油非索债、事件功能去重、文风示例边界与详略跨度。不把14段预设重复粘贴，也不把绝对禁词与亲密专用流程强套所有角色。
- 保留灰色11px斜体居中旁白、原气泡/编辑器/第三方美化、音乐/语音/ID卡/已发卡片。问号内说明改为符合面对面/异地新行为，没有增加说明面板或新设置。

## 具体实现与原版保护

- `chat_scene_reply.js`的`generateSceneSystemPrompt`从已恢复的线上生成函数复制，再只在独立副本适配；不调用线上生成器，也不向线上函数增加sceneMode分支。副本内不保留不可能执行的线上软件指令生成分支。
- uwu保留人设、用户设定、收藏记忆、世界书位置和防复读等原结构；新增`scene_rules`、`interaction_boundaries`、`character_continuity`、`narration_style`。tt保留世界定义/创作要领/正确理解/参考资料/历史占位符/准则，以场景与信息、互动边界、关系与延续、叙述与节奏写同等补充语义。
- outputRules只覆盖软件消息格式、动作禁令、状态栏与消息数量的表达冲突，不覆盖关系/距离/人物设定/玩家权限。JSON分段、双语和实际返回思考的分离继续沿用原协议。
- 默认思考仅在条目内容与原默认内容完全相同时构造请求临时副本，适配旧标签、手机断点和状态栏要求；保存预设及所有不匹配的自定义条目原样保留。保持选择、启用、预填与Token预览；自定义预设的强冲突仍需真实模型试用。
- `chat_scene.js`只扩充旁白请求身份：异地开关或角色状态改变，旧生成不得写入正式历史，按原草稿回退。
- 线上源文件本批未再改动。提交中`chat_ai_prompt.js`相对旧main的差异来自上一轮已授权的恢复：撤掉过去加入的旁白分支；没有改写线上提示文案，保留已授权世界书计划/记忆权限接入。历史范围、原请求顺序与群聊流程未改。
