# 记忆优化第二批：分批、检索与来源核对

日期：2026-11-22，Asia/Shanghai。起点 `0bd7fcb`；用户本轮明确授权“继续，直接推送到main”。本次 main 发布包含首批自动总结读取精简和本批修改，不把这次授权延续到以后。源码推送、站点部署和用户验收分别核验。

## 本批变化

- 自动总结新增可选的完整问答／输入预算分批，默认关闭。开启后按照相邻说话顺序保留用户消息及连续角色回复，不能装下的单条或问答不截断、不发送请求，显示原因；跨入最近保留区的问答等待完整来源。输入估算包含本次总结提示与格式开销；显式手动范围不被静默重分份，超预算时拒绝本次请求。它不自动识别所有事件边界，不声称使用了模型的官方分词器。
- 混合检索可选 RRF（把向量、关键词各自的名次相加）、中文词法的稀有词／频率／长度加权，默认关闭。原包含率词法与原加权策略保留。RRF 同分时按原余弦、词法分依次比较，避免旧记录仅因存储顺序抢占首位。准入仍按余弦或词法阈值检查，RRF 分不能套余弦下限，也不是事实正确率。
- 可选优先选择不同来源，默认关闭。适度扩大候选窗口，先选不同来源编号集合，再回填同来源的其他片段；不永久删除同事件中的独有细节。这是简单来源分散，不是语义事件识别或 MMR。
- 开启已有来源去重时，来源编号相同不再直接证明正文重复。总结确实包含原消息全文才排除该原消息；总结缺少取消、时间等内容时，原消息仍可检索。最近历史同样核对正文，显式收藏副本继续保留。手动合并快照的来源编号可沿关系读取；未实现跨独立备忘录注入通道的完整去重。
- 新增相邻句段扩展，默认关闭。命中分块后按标点补前后句，单侧扩展有界；不能补齐的超长片段不截断注入。稳定历史来源可附带前后一条可读旧消息，记录参与的消息编号、哈希与楼层，不跨撤回、禁用、隐藏或最近保留边界。扩展内容统一计入字符／Token预算，装不下时跳过整段，避免只留下“答应”却丢掉后文“取消”。普通多消息分组仍在本来源内扩展，不声称跨所有日记找到事件全貌。
- 新一轮检索与结果缓存复用重置旧的组装状态；无命中不会继承上一轮“已引用”。命中、已组装至上下文、实际接口发送是不同状态，后者继续查看既有请求诊断。
- 原检索诊断新增可点击来源与清洗后偏移，可对照对应原楼层；来源或配置变化时拒绝展示旧命中正文。新增默认脱敏复制：无查询、正文、人名、原始来源ID、地址、密钥或原始错误，来源ID转为本地校验标记。剪贴板权限不足时提供可选择文本手动复制；校验标记不是密码学匿名化保证。
- 独立索引清单记录模型、维度、清洗／分块版本、任务类型、前缀与分块设置的校验标记，清单只复制白名单字段。同空间混维度写入拒绝且保留旧索引。兼容无新元信息的旧缓存；现有内容哈希、来源指纹、增量写入、跨页面版本检查与候选模型回退继续有效。新版本标签用于说明，不无条件废弃内容相同、仍可复用的缓存。
- 现有缓存清单显示处理版本、向量数值的大小估算、当前来源／设置是否变化。旧模型／旧存档缓存可以保留回退；估算不是浏览器实际磁盘占用。本批未加入当前空间失效分块的专门清理操作，不把标签显示写成完整清理功能。
