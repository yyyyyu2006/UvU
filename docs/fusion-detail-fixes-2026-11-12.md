# 二改面板六处细节修复

## 本次变化

1. 日历选中日期、日程周条及生成行程按钮统一为 #D4E5EF，使用深色文字。
2. 子页面返回键紧靠关闭键，两键间距 12px，保留原事件及关闭逻辑。
3. 二改弹层开关开启色改为 #C9EAF8，滑块位置仍表示开关状态。
4. 表情说明与发送文件弹层按内容决定高度，宽度上限 366px；长预览和短屏保持内部滚动，保存、取消仍可达。查看文件与编辑副本维持原尺寸。
5. 记忆底部导航压缩为 40px 高，内部按钮 32px 高，文字不换行；添加记忆按钮单独保留。
6. 记忆时间线使用独立 44px 时间栏及 16px 栏间距，日期不再负向溢出，竖线不穿过标题、正文或操作按钮。

## 原因

- 日程旧样式的选择器优先级更高，覆盖了日历局部浅蓝色规则。
- 关闭、返回按钮同时具有自动右边距，将返回按钮挤向中间。
- 短表单沿用固定弹层高度；记忆卡片内边距被新样式覆盖，但旧时间线及日期负边距仍然生效。
- 记忆导航继承整行宽度和较大按钮内边距，与添加按钮争用窄屏空间。
