# 二改面板 · Lenso 第三版落地

2026-11-12。依据已确认的第三版草稿，调整真实面板的 DOM 分区和专用样式，不迁移应用框架。

## 实际变化

| 区域 | 内容 |
| --- | --- |
| 备忘录 | 标题、角色、筛选、搜索、最近记录依次排列；记录方式独立分组，整理聊天留在设置中 |
| 自动总结 | 先显示最近真实摘要，再显示自动规则、范围和 API；执行与保存区分主次 |
| 向量记忆 | 显示实际本地数量，检索设置和索引管理作为独立任务入口 |
| 酒馆 App | 全屏；角色存档、审核、交接、已审核日记和连接分组，底部导航 |
| MCP | 总开关、服务卡、所选服务管理、角色权限和调用记录分开；状态来自实际诊断 |
| 文件 | 上传、解析信息、真实正文、编辑副本和更多操作依次排列 |
| 日历与环境 | 保留日期手势，统一分组与内部滚动；修复心情选中日期对比度 |
| 设置弹窗 | 动态设置、头像、好友关系、导出选项、资源、表情及已有子页统一层级 |
| 管理工具 | 存档、转发目标、CSS 导入、通知偏好与主页预设统一标题和动作区 |
| ST / TT 插件 | 独立仓库调整任务入口、审核、正文识别分区；修复长列表压缩遮挡按钮 |

灰白底、20px 内容圆角、28px 弹窗圆角、30px 常规字重标题、14px 正文、绿色开关、蓝色主要动作。短屏内部滚动，保留主题模式与减少动效设置。

## 保护范围

- 1900 原版 CSS、美化、提示词、历史截取、上下文顺序和回复请求代码不变。
- 音乐 App、音乐／一起听卡片、发送后的文件卡片不变。
- PNG ID Card 绘制、作者署名和透明圆角不变，只调整导出选项。
- 动态帖子与实际评论、状态栏与 Token、原文字图面板不加入新样式。
- MiniMax／导演和备份继续内嵌原页面；未重画宿主 API／设置界面。
- 用户主题、图标、CSS 与数据不重置，备忘录入口继续在文件旁。

## 草稿与真实功能

生产只显示真实记录。草稿中的样例数字、演示角色、最近文件、附言和检索测试不能作为已有功能。保留现有参数、安全说明与保存入口。部分演示页使用已有子页承载，因此不将 78 张原型全部宣称为独立完成的功能或逐像素一致。
