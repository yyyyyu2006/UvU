# 状态栏滑动、自主头像与真实环境功能

本次是现有框架上的增量功能。原 UwU / T.T、日记与合并、思维链、语音视频提示词正文未改；世界书插入位置、聊天消息角色和顺序未调整。新增可选功能默认关闭。

## 1. 状态栏滑动

- 原因：Token 翻面卡片的隐藏面仍可能参与 iframe 的触摸交互。相同内容在原容器可以滑动，在新增翻面容器中失效。
- 修复：明确控制非当前面的 visibility、pointer-events、inert 和 aria-hidden；保留原状态历史、懒加载和横向分页。
- 浏览器触摸验证：390px 宽度，含 iframe 的三页历史从 scrollLeft 780 切换到 390；翻到 Token 面再返回保留原页，反向滑动可回到最新页。
- 未修改用户状态栏模板及其中的 HTML/CSS。

## 2. 角色自主头像

入口：私聊设置 → 功能 → 角色自主头像 → 设置。

- 默认关闭，可配置检查频率与自定义条件；提供保存并检查、恢复上个头像。
- 正常回复完成后按频率独立判断；本存档的新隔空投送生图完成后也尝试按频率检查。
- 复用图片识别 API 路由。最多处理最近六张真实图片；图片 SHA-256、识图服务地址和模型均相同时复用描述。
- 候选关联消息 ID / 图片 ID。生图还关联角色、存档和原消息，不读取其他角色或存档的图片。
- 模型只能返回候选 ID，程序校验后下载和压缩为最大 256px 的头像。文字描述本身不能变成头像；模型不能指定任意新 URL。
- 独立判断请求包含角色设定、近期已送达聊天、用户条件及图片描述，不向主聊天请求增加头像动作指令。
- 明确换头像请求独立于日常检查频率。针对“换这对情头”等请求，以及同一话题紧接的“你用男生”等选图补充，独立发送请求文本和关联候选图描述；仍由角色结合对话决定。一次性请求写入头像状态以避免重复触发；撤销、拒绝、转发和无关聊天不作为动作请求。并发新消息会合并为有限次重试，且不跨存档重放。
- 保存失败回滚本次字段；切换存档、改变人设、修改头像/设置、撤回候选消息后丢弃过期判断。
- 新头像保留一个前任头像供恢复。同一图片已作为当前头像时不会反复压缩、更换。

限制：识图及动作判断会增加独立 API 用量，不包含在主聊天本轮 usage 中。识别质量取决于模型。旧生图若没有存档/消息关联信息，不会猜测其归属；可把图片重新发送到当前聊天。外链不允许跨域读取时不更换头像。

## 3. 日历、定位、天气和异地模式

入口：更多 → 日历 → 设置。私聊设置 → 功能 → 天气与异地模式，可配置 char 城市与本角色的 AI 环境感知。

- user 支持手动城市搜索或点击“定位并获取天气”；授权后直接使用内置公共服务、启用并保存城市信息和读取天气，无需玩家填写 API/MCP。定位失败、拒绝定位后可以手动搜索。该快捷操作切换到内置公共服务但保留自定义 MCP 配置。
- char 城市由用户设定；异地模式显示双方当地日期时间，按 IANA 时区计算时差，处理夏令时和非整小时时区。
- 位置、服务配置全局保存；异地模式、char 城市及 AI 感知开关随角色存档保存。
- 月历显示真实日期、节假日和中国调休工作日，支持切月、今天和日期详情。
- 天气缓存十五分钟，节假日缓存一天，国家覆盖清单缓存七天；可主动刷新天气。
- 可丢弃缓存独立存放；不复制完整数据库。MCP 缓存按访问身份隔离且不写入 localStorage。
- 日历关闭后停止时钟定时器，取消未完成环境请求；月份切换丢弃上一批结果。设置保存后刷新已打开的日历。
- 网络失败、无覆盖或年份未公布时明确显示未获取，不伪装成晴天或没有假日。

### 公共服务

- 城市搜索：Open-Meteo Geocoding。
- 定位坐标转地区：BigDataCloud reverse-geocode-client。
- 天气：Open-Meteo。
- 中国节假日：本地 2026 年小型数据优先，其他年份从 holiday-cn 查询。保留来源公告与 MIT 许可。
- 其他国家：Nager.Date，先检查国家覆盖；可填 ISO 行政区代码以筛选地方条目。未指定时仅列全国条目。
- 服务条款、覆盖和可用性由提供方决定。页面关闭后不持续定位、查询或产生新的 AI 请求。时间显示使用设备时钟。
- Open-Meteo 免密钥免费 API 仅供非商业用途，限 600 次/分钟、5,000 次/小时、10,000 次/日和 300,000 次/月，且无正常运行时间保证；天气界面提供 Open-Meteo 来源链接。BigDataCloud 客户端逆地理编码依当前公开 URL 直接查询。公开 API 不是 MCP 协议，也不保证不限流或所有地区始终可用。

### 远程 MCP

支持 Streamable HTTP 的 initialize、initialized notification、tools/list、tools/call、协议版本和会话头；支持 JSON、SSE、多数据行及分块响应。会话失效（404）可重新初始化一次；请求有超时和取消。

配置工具名及 JSON 参数模板，允许各服务使用不同参数名。工具结果须返回 structuredContent 或 JSON 文本，约定如下：

- 城市搜索：`{results:[{name,latitude,longitude,countryCode,timezone,subdivision}]}`。
- 逆定位：上述单个地点对象。
- 天气：`{temperature,text,observedAt}`，摄氏度；也接受 Open-Meteo 的 current 格式。
- 假日：`{days:[{date,name,isOffDay,counties}]}`，date 是 YYYY-MM-DD；counties 是适用行政区代码数组，全国条目省略。

MCP 服务需允许 Pages 站点跨域访问，以及 Content-Type / Authorization / MCP-Protocol-Version / Mcp-Session-Id 请求头；使用会话时需暴露 Mcp-Session-Id 响应头。令牌由每名玩家在设置中填写，保存于本机及其设置备份，不写进仓库。未配置真实 MCP 服务时可以使用公共 API 模式；不把模拟服务测试描述为所有 MCP 提供方均已验证。

### 主聊天兼容

只开启日历显示时，不增加主聊天上下文。单独开启“允许本角色的 AI 感知真实环境”后，才在原系统正文之后追加标识明确的环境资料，不发送精确经纬度、服务令牌和 MCP 地址。请求最长等待八秒；失败不阻断原有聊天，停止回复可以取消环境查询。Token 面板增加真实环境分类估算。

增加环境信息可能影响模型回复和输入用量；不承诺开启该功能后与旧版回复完全相同。

## 4. 备份与存储

沿用原 JSON / gzip EE 格式与 IndexedDB 表，无数据库版本升级。新字段作为可选扩展；导入旧备份不要求这些字段。全局设置备份增加 environmentSettings；头像动作状态和异地配置按聊天存档导入导出。新增字段提供结构校验，损坏数据在写库前拒绝。

## 5. 验证结果

- 328 项 Node 回归测试通过，含新功能默认关闭、API 请求体对比、明确头像请求绕过间隔一次、请求去重/撤销/排队/存档切换/保存回滚、定位服务默认及环境模块缓存、异常数据、MCP 协议、夏令时和取消。
- 原提示词兼容审计 114 项通过：UwU / T.T、独立覆盖、群聊、人设世界书、日记合并、OpenAI/Gemini 最终请求、思维链预填、聊天占位符、语音视频。
- 全部 77 个 JavaScript 文件语法检查通过；入口脚本合并检查通过，无新增顶层命名冲突、无缺失本地脚本。
- Chrome 触摸模拟验证状态历史双向滑动、Token 翻面后保留页码；320/390px 验证头像设置、免配置授权定位与天气、保存失败回滚、拒绝定位后的搜索入口、环境设置、日历的滚动和无横向溢出，无页面异常。
- 真实公共接口连通：上海搜索返回 Asia/Shanghai、天气返回有效温度、美国 2026 年假日返回有效条目；中国年度数据保留 39 个放假/调休条目。
- MCP 使用模拟 HTTP/SSE 响应验证协议，尚无用户自定义服务的凭证可做真实服务验证；未调用付费模型测试自主决策，也未代替真实 iOS/Android 设备测试。
- 改动资源更新缓存版本号；未修改 PWA/全屏、原用户美化或升级任何 CDN 库。
