# 2026-11-04 备份、向量检索和 Token 统计改进

本次改动保持原聊天请求结构、消息角色顺序、世界书注入位置和 UwU / T.T / 日记提示词模板。Token 分类只读取已构造的请求体，统计失败也不能阻止聊天。

## 修改范围

- Token：从最终请求文本分项，避免把通话 CoT、被向量替代的整篇记忆和 T.T 系统消息内的历史重复计入。空上下文不再回退全部历史。世界书合计始终可见，详情仍可展开收起。
- API 用量：分别标记输入、输出、总量是否由接口提供；缺失字段不冒充实际零值。差额明确为本地估算与接口返回值之差，不表示新增扣费；推理字段不再与本轮输出重复相加。
- 备份导入：Worker 增量解析 gzip / JSON，跳过未选分类的值，同时校验其 JSON 语法。不再拼接整份解压文本。沿用旧的原始 JSON 和 modules JSON 包装，以及解压后 512 MB 上限。
- 备份导出：流式生成 JSON、直接流式压缩成 EE，减少巨型字符串与未压缩 Blob 的临时副本。无压缩支持时继续导出 JSON。
- 事务：角色按一条、其他表按小批次写入，所有批次仍在同一个事务中；后续批次失败也回滚全部写入。活动存档同步及未勾选分类保留行为不变。
- 深层校验：检查自动记忆来源、来源 ID 重复、已提交记忆的范围、向量分块边界和数值维度。旧数据缺失可选字段与未知扩展字段继续接受。
- 备份分类：向量索引归属聊天记录，不混入仅角色设定的备份。导入旧历史但未携带索引时清理对应派生缓存，原总结文本保留，启用向量时按需重建。
- 向量：缓存未变化记忆的分块计划；精确余弦计算使用 Worker 或主动让出主线程的回退。临时打包限制在 16 MB 内，避免为巨型库复制全量数值。
- 存档一致性：保存失败时同时恢复原活动索引和原存档的深拷贝快照，不修改新活动分支。独立向量 API 已填写时不再借用总结 API 的凭证；无独立配置的旧数据仍沿用原路由。
- 旧设置文件：保留 js/settings.js 并标为 legacy，入口测试禁止与拆分模块一起加载，不直接删除原文件。

## 验证

- 297 项 Node 回归通过。
- 114 组原版提示词及最终请求体比较通过：私聊 UwU / T.T、群聊、人设、世界书、日记、CoT、预填充、历史占位符、语音和视频通话。
- 增量解析与 JSON.parse 对照：300 组嵌套数据、多个文本切分边界、转义、中文与表情符号、无效 JSON、旧 JSON 与 EE。
- IndexedDB 后续批次失败全部回滚、未勾选提示词保留、旧历史索引失效重建、切存档期间向量保存失败的局部回滚。
- Worker 与原精确余弦计算结果一致；Worker 不可用时回退。
- 本地无头 Chrome 验证真实 Worker、EE 解析，以及 360 / 390 px 面板宽度、世界书展开收起。测试使用合成数据，没有发送真实聊天或调用付费 API。

## 边界

没有加入近似向量索引，也没有自动删除候选或截短上下文；历史候选构造和来源一致性检查仍有线性遍历成本。选中数据、存档副本及数据库写入仍消耗内存，单条巨大字符串也需要解析空间，不能保证任意大小备份都可在低内存手机导入。没有新增临时数据库或更改数据库版本。

分项继续使用字符规则估算，不是模型官方 Tokenizer。图片费用、服务端隐藏包装和第三方站点计价无法从文本分类精确推断。未进行 iOS / Android 真机、真实第三方 API 或所有自定义美化组合测试。
