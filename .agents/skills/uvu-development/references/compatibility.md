## 基线

兼容是保护原版流程，不是把全部二改回退。比较本次函数、调用和实际请求再处理差异。tests/legacy_1900_compat.test.cjs 读取 UVU_1900_ROOT，默认 C:/Users/15271130817/Desktop/1900版uwu。换机器设置真实路径；基线缺失或测试跳过时报告未验证。

## 回复与上下文

新增选项关闭时保护此路径：

```text
chat.history.slice(-chat.maxMemory)
  → filterHistoryForAI()
  → 原版提示词与上下文组装
  → 原版 provider 请求／响应解析
```

- 核对提示词文本、世界书筛选／排序、收藏记忆、历史范围、顺序和角色；UI 任务不要求改写这些路径。
- 自动总结隐藏、向量、环境、MCP、酒馆记忆与高级世界书规则只在相应选项启用后介入，检查关闭、默认与旧数据迁移状态。
- 区分“未传世界书计划”和“明确传空计划”。单次请求的激活、随机结果、提示词与 Token 统计共享结果，不因统计或直接调用重复激活。
- 导演 API 与总结是独立阶段，不为它们改写普通聊天基础提示词；控制标签不进入朗读正文。非本次原版优化留待用户判断。

## 桥接与异步

- 启用、配对、可达、绑定和剧情模式分别判断；配对 Token 不代表启用或进入线下。
- 关闭互通后停止检查／注入；超时、鉴权和网络失败不冒充可信线下状态而中止普通回复。
- 有效绑定会话的明确线下状态只影响该会话，其他角色、存档和新聊天不继承。
- 任务启动时固定角色ID、存档ID、来源和会话／批次ID；完成后核对身份与版本，结果不能写到新的 currentChatId。
- 名字只用于显示，不能作为唯一绑定键；检查重名、改名和切换。

## 剧情与记忆

- 按楼层保留来源，支持整层审核、全选与编辑。正文识别用明确标签及可配置回退，不声称覆盖所有预设。
- 导入只产生待审内容；审核后按当前流程写入对应角色的 memoryJournals／日记。正文与总结分开，失败不静默替换原文。
- 选摘要时复用第三人称摘要总结能力，审核摘要后才作后续记忆。不混入状态栏、代码、小剧场与未批准内容。
- 写入和注入是两个状态，保留收藏、权限与开关；关闭注入不删除已批准日记。
- 按来源、楼层或批次去重；刷新／重试不重复写入。刷新固定绑定目标，不回退主存档或其他聊天。

对本次路径检查关闭、启用、失败／超时、角色／存档切换。有限样本不能推出全部原版行为或全部手机兼容。
