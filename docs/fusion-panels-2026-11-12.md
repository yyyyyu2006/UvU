# 二改面板浅蓝融合版

本次将已确认草稿接入实际功能页面，主色为 #D4E5EF。白底、细线分隔、紧凑控件和正文留白延续草稿；列表使用真实数据，不写入草稿演示内容。

## 可见调整

- 备忘录、记忆／总结、向量记忆、MCP、文件准备、日历、动态设置、角色设置、通知、存档、资源等二改弹窗共用新的标题、间距、按钮和底部操作区。
- 酒馆保持全屏，先显示角色与存档入口，再显示剧情审核和线上交接；保留连接状态、教程和原有操作。
- 备忘录与酒馆采用短幅背景、右下重叠头像及左侧姓名。点击头像或背景进入“外观”。
- 面板头像按角色保存；备忘录与酒馆背景分别保存。支持 PNG／JPEG／WebP、小于等于 15 MB 的文件，保存前缩小尺寸并转为 WebP；支持预览、取消和恢复默认。
- 外观属于角色元数据，不复制到每个聊天存档；保存失败回退，角色选择改变时拒绝提交。
- 文件准备页依次显示上传、当前私聊、说明和操作。文件就绪后显示正文预览、编辑和发送操作，不增加接收角色选择器。
- MiniMax 与备份仍在原生 API／数据页面内，新增控件采用轻边框和所在页面背景。

## 保留范围

未修改 1900 原版样式文件、提示词和回复链路；未修改音乐 UI、导出 PNG 的 ID Card 绘制、发送后的文件／音乐／一起听卡片、动态实际评论、状态栏和 Token 样式、原生文字图界面。面板头像不会替换聊天头像。已有主题与字体入口保留。

- npm test：1,235 项通过，0 失败，0 跳过。
- lenso_panels_browser.cjs：实际功能页在 320×568、390×420、390×844、768×1024 下的边界与横向溢出；文件解析／编辑；外观上传、保存刷新、取消、重置、角色隔离、保存失败回退、切角色阻止保存；内嵌语音／备份；未受影响的音乐与聊天截图；ID Card 绘制及透明圆角。
- reported_ui_regressions_browser.cjs：通知去重、展开控件、紧凑重回面板、天气和内嵌设置通过。
- backup_memo_review_browser.cjs：备份导入、取消、坏文件恢复、备忘录审核删除／撤销和短屏操作通过。
- minimax_speech_browser.cjs：音色搜索、角色覆盖、读音与保存通过，未调用收费合成接口。
- moments_social_browser.cjs：动态设置、NPC 编辑、身份区分和持久保存通过。
- 修改的 JavaScript 语法检查与 git diff --check 通过。
