# 分类备份与存储说明（2026-11-06核对）

在主页「数据管理」切换「导出分类」或「导入分类」。两个页面分别记住当前会话的选择；常规七类默认勾选，「相册／工坊／阅读数据」默认不勾选，点击全选时也会包含它。分类导出不删除原设备数据。

## 覆盖范围和兼容性

- 聊天记录包含所选角色与群聊的聊天存档、日记/记忆及相应运行数据；角色设定和聊天记录可分别迁移。按ID合并，未勾选类别保留。单独导入聊天不会改写本机人设，单独导入角色设定保留原聊天；文件缺少的设置字段保留本机值。
- 世界书、外观中的表情集合沿用整表替换规则。提交前预览显示新增/更新/保留数量、缺少的世界书绑定和外链依赖，确认后才进入事务。
- 可选「相册／工坊／阅读数据」包含对应缓存快照；相册只恢复已存在的角色和存档，工坊/阅读数据按包内快照替换。浏览器通知授权、MCP凭据保险库、桥接设备Token与本机临时草稿不是全部网站数据备份。
- `.ee` 是gzip压缩的JSON，未增加新的加密格式或版本门槛。支持旧带modules包装及无包装JSON；字段缺省迁移只处理可安全补默认值的情况，损坏字段指出路径并拒绝提交。不同版本可能忽略新功能字段，不能据此承诺全部新增功能双向可用。
- 图片、字体和组件外链保留原地址，导出不会自动把网络资源下载打包；文件中的外链失效时，完整配置也无法恢复远端资源。

## 密钥和向量索引

「导出包含API密钥」默认选中以保留原备份语义。分享前取消：已知API设置、独立记忆/向量、语音导演、环境服务和工坊兼容字段会清空密钥，包内标记为脱敏。用户自行写在提示词、URL参数或任意文档里的秘密不属于结构化密钥字段，请自行核对分享内容。

导入带脱敏标记的备份可选择保留本机相同接口的密钥或清空。保留需接口/供应商一致；预设按稳定ID匹配，不按数组下标匹配。工坊gpt/novelai兼容密钥分别核对对应地址；地址缺失或变化不会套用另一接口的密钥。旧版没有脱敏标记的备份按原方式恢复。

「导出包含向量索引」默认选中；取消时在克隆数据前跳过索引，保留记忆原文、总结和配置。恢复后需重新建库，嵌入服务可能再次计费；不会因此删除剧情。

## 内存、取消和事务

有Worker能力时，后台解析器流式解压并只保留勾选分类，不创建完整解压JSON字符串或未选类别对象。解压上限512MiB；解析阶段可取消，Worker立即终止，晚到结果被忽略。进度是已读取解压字节，不代表总完成百分比。无Worker降级只接受8MiB内备份；降级同步JSON解析无法在计算中立即打断。`.ee`需浏览器支持gzip解压。

选中对象、跨线程复制和提交前数据仍可能同时驻留。这里没有实现磁盘暂存分批切换，没有测出真实手机超大备份峰值，不能说已消除内存风险。大数据优先按类迁移，并保留来源备份。

校验与确认后，仅写本次选择的表和设置，仍由一个IndexedDB事务保证原子性；成功后才替换内存。进入事务后不提供强行取消按钮。不会因导入一类再调用全局saveData重写未选类别。

普通saveData沿用本轮开始前的逐条读取比较、仅写变化记录和活动存档同步；此次没有再改其候选范围或增加变更日志。读取比较成本仍在，不能把减少写入说成消除所有保存开销。聊天渲染、虚拟化和移动端模糊效果本轮暂缓。

## 查看容量与验证

页面容量按JSON的UTF-8字节估算；不等于压缩文件大小或浏览器实际磁盘占用。导入确认显示浏览器reported quota/usage的剩余估算，不能保证写入成功；空间不足应导出保管后按类别清理。

开发测试使用Node运行`node --test --test-isolation=none tests/*.test.cjs`。备份测试验证Worker取消、晚到结果、事务失败、分类保留、旧日记范围、嵌套审核字段、密钥脱敏与同接口恢复。没有调用玩家真实API，也没有自动改写原1900提示词。
