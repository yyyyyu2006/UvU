# 中国节假日数据

`cn-2026.json` 来自 NateScarlet/holiday-cn，包含 2026 年全国放假和调休工作日，保留原始 `papers` 公告来源字段。

- 数据仓库：https://github.com/NateScarlet/holiday-cn
- 年度文件：https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/2026.json
- 对应官方公告：https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm
- 获取日期：2026-11-04
- 原项目 MIT 许可见 `LICENSE-holiday-cn.txt`。

仅增加一份小型年度数据，不改变 UwU 原有备份或资源加载方式。其他年份先尝试本目录对应文件，再读取该数据仓库；尚未公布或无法获取时明确显示未获取，不推算放假和调休。
