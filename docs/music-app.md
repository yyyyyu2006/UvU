# 音乐 App 使用说明

桌面新增独立的「音乐」图标；「酒馆」入口保留。私聊的加号面板也能打开音乐。

## 不连接账号也能使用

底部有「主页」「新发现」「广播」「资料库」「搜索」五栏。主页继续最近播放；新发现展示自己的歌单、收藏与专辑；广播将已有音乐或某位艺人的歌曲组成随机播放队列，不是平台直播节目。没有音乐时可以搜索或导入。页面使用已确认的白色草稿排版，右上角账号设置内可切换深色、导入音乐或返回小手机。

资料库按「播放列表」「艺人」「专辑」「歌曲」「本地音乐」浏览，下方显示已收藏或加入歌单的专辑；播放记录不会自动变成收藏。每个音频文件最多 30 MB，支持浏览器可解码的 MP3、AAC/M4A、WAV、OGG、WebM、FLAC。支持的容器不代表设备支持所有编码。音乐单独存入本机 IndexedDB；刷新不自动播放。

歌曲的「更多」菜单可收藏、加入歌单、排到下一首、分享或邀请一起听。本地歌曲可从这里删除，清理音频、资料库、歌单和队列；已发送的卡片仍保留文字资料。

本地歌曲的「更多」→「编辑歌曲资料」可改歌名、歌手、专辑和封面链接，不改音频文件。导入 MP3 时会尝试从文件前 256 KiB 读取 ID3 标题、歌手和专辑；没有可识别资料时使用文件名。

「资料库」→「播放列表」可进入喜爱歌曲和自建歌单。自建歌单中的「管理」或右上角省略号开启重命名、排序、全选和批量移除；移出歌单不会删除本地音频。搜索保留最近 12 个成功搜索词，可手动清空；切换导航再回来会保留本次搜索结果和查看位置。

歌词居中显示，隐藏 LRC 时间标签和文件元信息；有时间轴时高亮当前句。有翻译时可切换原文与翻译。手动滚动会暂停自动跟随，点击「跟随播放」恢复。原歌词及翻译的来源数据保留。

底部悬浮迷你播放器可暂停、下一首、展开。展开后可拖动进度、调整音量，底部三个按钮分别打开歌词、一起听、队列。右上角省略号提供播放模式、15/30/60 分钟定时关闭、分享和歌曲菜单；音量是否可由网页调整取决于设备。MiniMax 语音播放时会暂停音乐，结束或手动暂停语音后尝试恢复；期间手动操作了音乐则尊重该操作。

播放模式有「顺序播放」「列表循环」「随机播放」「单曲循环」。歌曲自然结束时按模式接续，顺序播放到队尾停止；随机播放尽量走完一轮，上一首按实际播放历史返回。「播放下一首」优先于随机顺序。队列可上移、移除、指定下一首和清空；清空时保留正在播放的歌曲。

播放失败会区分浏览器权限、格式、网络、音源不可用与限流；再点播放可重试获取音源。「跳过不可播放歌曲」默认关闭，开启后最多连续尝试 5 首或当前队列长度，不循环重试；权限与限流错误需手动处理。手动暂停后发生延迟错误不会自动切歌。

音乐源设置里的「清理缓存」清除临时歌词、公共源搜索结果及播放地址等数据，不删除歌单、本地音频或浏览器图片缓存。歌词临时缓存最多 20 首，10 分钟过期。暂未加入整首音频下载缓存或设备投放。

## 网易云和 QQ 音乐

### 公共源：不用配置服务器

打开「音乐」→「音乐源」（或右上角账号按钮），开启「GD 音乐台 · 网易云」。然后进入「搜索」，选择「公共源」，输入歌名或歌手即可搜索；点击歌曲尝试播放。无需填写服务地址，也无需登录。公共源默认关闭。

本通道由 GD 音乐台提供，供个人学习、非商业使用，固定请求 128 kbps 音频。服务公布的限制为每 5 分钟 50 次请求；页面会缓存部分结果，并在接近限制或收到限流时提示稍后重试。网络、地区、服务可用性及平台限制可能导致部分歌曲无法播放，搜索到歌曲不代表一定能播放。

公共源目前只接入网易云，不提供 QQ 登录、账号歌单或公共 QQ 搜索。公共源歌曲也可收藏、加入歌单、分享与邀请一起听；读取歌词需要额外请求。关闭公共源会停止该来源的播放，已收藏的歌曲资料仍保留。

来源：[GD 音乐台](https://music.gdstudio.xyz/)。公共源不接收音乐服务的登录令牌或账号 cookie；临时播放地址不会写入资料库或备份。

### 账号源：登录与账号歌单

这两个平台通过独立的音乐服务连接。GitHub Pages 只能放前端文件，不能运行平台登录服务。当前仓库提供服务代码，**没有替你部署可供所有玩家登录的公网服务**。

1. 在支持 Node.js 22 或更高版本的电脑/服务器上取得 UvU 仓库，进入仓库根目录。
2. 执行 `node services/music-gateway/setup.mjs`。这会下载固定版本的平台适配引擎到被 Git 忽略的 `.runtime`，不会将玩家账号文件提交到仓库。
3. 复制 `services/music-gateway/.env.example` 为同目录 `.env`，设置 `MUSIC_ORIGINS` 为实际网页来源，例如 `https://yyyyyu2006.github.io`。来源不包含 `/UvU/` 路径。
4. 执行：

```sh
node --env-file=services/music-gateway/.env services/music-gateway/start.mjs
```

5. 线上网页请按 [服务部署说明](../services/music-gateway/README.md) 配置 HTTPS。网页与服务在同一台电脑时可测试 `http://127.0.0.1:8787`；手机上的 `127.0.0.1` 是手机自身，不能指向电脑。
6. 部署者可以在 `js/modules/music_config.js` 的 `endpoint` 填入验证通过的 HTTPS 服务地址并更新网页。玩家打开「音乐」右上角账号按钮即可扫码；自建服务地址放在「更换音乐服务」中。
7. 选择网易云或 QQ 音乐「扫码登录」，用相应官方 App 授权。二维码会过期；退出登录或新建二维码会作废旧授权流程。同机操作可保存/截取二维码后使用官方 App 的相册识别，是否支持以平台为准。
8. 登录后可以读取账号歌单；搜索可选择全部、网易云、QQ 音乐。一方出错会保留另一方结果。平台会员、地区、版权和试听限制仍然生效，没有解锁会员功能。

默认服务会话在内存保留 24 小时，重启后需重新登录。「记住此设备」需要服务配置加密 vault；新会话最长 7 天。修改已有会话的选项只改变浏览器是否保留访问凭据，不延长服务端有效期。具体配置见服务 README。

### 将平台歌单导入资料库

1. 打开「资料库」→「播放列表」→「导入歌单」。
2. 粘贴网易云或 QQ 音乐的完整歌单链接，也可以粘贴包含该链接的分享文字。仅填写数字歌单 ID 时，请先选择平台。短链接请先在官方平台打开，再复制完整歌单链接。
3. 点击「预览歌单」，确认歌曲列表并修改歌单名称，然后点「保存歌单」。账号设置中的「歌单」打开后，也可以点「导入到资料库」进入相同预览流程。

导入复用已配置的音乐网关，不是公共源接口；私密或受限歌单可能需要先登录对应账号。未连接时，面板会提供连接入口。默认名称使用平台和歌单 ID，账号歌单沿用其原名。

保存的是本地歌单和歌曲资料，不下载音频。打开保存的歌单，开启「公共源播放」，即可用 GD 网易云公共源尝试播放，无需重新导入，也无需扫码登录。开关也在「音乐源」中，此偏好用于所有网易云和 QQ 歌曲；关闭后恢复账号源。网易云歌曲沿用原歌曲 ID；QQ 歌曲按歌名、歌手匹配，并用专辑区分同名版本。找不到一致记录或存在多个版本时会提示手动搜索，不会任取第一首。歌词跟随匹配结果，歌单中的原平台、歌曲 ID、排序及分享资料保留。切换偏好会停止当前平台歌曲，请重新点播放。

匹配按需进行，只临时缓存有限的匹配资料，不保存播放地址。公共源仍受可用性、请求频率和版权等限制，无法保证每首歌都能播放；关闭公共源会停止公共播放并恢复账号偏好。读取平台歌单仍需网关，公共播放开关只改变播放和歌词来源。每次最多导入 1000 首，读取结果超出时会在确认前提示只保存前 1000 首。平台接口只返回部分歌曲时，预览只能显示实际读到的内容。

分页歌曲会按平台和歌曲 ID 去重并保留顺序；关闭预览、请求失败或切换网关不会保存半份歌单。确认后一次性保存，存储失败会回滚；可以在资料库继续管理或删除。相同歌单再次导入会新建一份，不覆盖已有编辑。

平台接口可能变化，真机扫码、账号权益与移动端后台音频仍需实测。账号源的自动化验证使用本地接口和音频夹具，没有使用真实账号或收费接口。本轮用真实接口与 Chrome 验证了 QQ 歌曲资料匹配《Take Me Hand》（WONDER Tourism），并成功播放对应的网易云公共音频；这不代表所有歌曲或设备均可播放。

## 分享和一起听

从私聊加号进入音乐后，分享固定发给该角色和进入时的存档；存档已切换会提示重新选择。从桌面进入，则在发送时选择角色。

分享面板可以「读取歌词」，保留或编辑需要的片段，最多 2000 字符。char 接收歌名、歌手、专辑、时长与附上的歌词；不会直接听到音频。

「一起听」发出一条邀请。点击原有回复按钮后，char 可根据角色设定接受或婉拒；没有邀请时不加入音乐行动规则。接受后才尝试本机播放，浏览器拦截时需点击卡片的播放按钮。卡片可以撤销邀请或结束一起听，邀请 30 分钟未处理会过期。

成功一起听后，小手机顶部显示常驻状态条，标出绑定角色与歌曲。切换其他聊天、返回桌面或进入音乐 App 都保留；打开播放器、歌单、歌词或队列面板时，状态条移到面板标题下方，关闭面板后回到手机顶部。手动换歌、自动下一首不会因面板遮挡而隐藏状态条；暂停或停止播放时显示“已暂停”。点击歌曲打开播放器，右侧按钮可暂停、继续或结束一起听。原角色存档被替换、邀请被删除/撤回、关系已不允许互动时清理，避免关联错误。页面关闭或刷新后不自动恢复播放绑定。

分享与一起听卡片提供喜欢、上一首、播放/暂停、下一首、队列和进度条。只有当前播放歌曲显示实时进度；历史卡片始终保留当时分享的歌名和封面资料。

邀请接受并成功播放后，可在原卡片开启「连续一起听」，继续听开启时队列中的歌曲。换成新队列或播放队列外歌曲后保留原一起听状态并显示暂停，不把其他歌曲归给该角色；点击状态条继续可回到原歌曲。切换原会话存档、结束邀请会解除绑定，回到原存档需手动播放卡片重新建立。此选项仅在当前运行期间有效，不会自动发消息、请求 AI 或改写原卡片。

这是与 AI 角色的聊天互动，不是另一台真实设备的同步播放服务。未开启「连续一起听」时，切换其他歌曲会暂停原一起听状态，浮条保留，直到手动结束或原邀请失效。分享本地音乐只分享资料，另一台设备不会收到音频文件。

## 角色歌单

点击音乐顶部的耳机图标，或进入「资料库 → 角色歌单」。选择角色后点击右侧刷新按钮，使用已配置的聊天 API，根据角色人设、最近六条有效文字消息生成最多六首推荐，再从已启用的搜索源解析真实歌曲。刷新会消耗一次模型请求；同名版本无法确定或歌手不一致的歌曲不会加入。未匹配到歌曲、网络失败或刷新中切换存档时保留原歌单。

选定角色会在本机记住；歌单与主动邀请开关随角色当前存档保存，不会写入其他角色。点击「播放全部」可加入现有播放器队列，也可点击某一首播放，继续使用原有单曲、列表和随机播放模式。

开启「允许主动邀请一起听」后，角色可以在正常回复时选择其歌单中的歌曲发出邀请。角色不会被强制每次邀请；存在有效邀请时不重复发起，主动邀请至少间隔 30 分钟。收到的白底卡片上，播放图标是接受，叉号是婉拒；接受前不会自动播放，邀请有效期 30 分钟。关闭开关后，普通回复不增加这部分歌单提示。不会自动启动额外的聊天轮次。

## 备份和隐私

音乐设置和资料库随「基础设置」分类备份，聊天卡片随聊天记录备份。备份不含平台 cookie、音乐服务访问令牌、临时播放地址或音频文件。恢复到其他设备后，本地歌曲需重新导入；原有资料和卡片仍可查看。备份不会复制账号登录状态。

音频持续后台播放和锁屏媒体控制由系统、浏览器与 PWA 的实际支持决定。浏览器关闭后网页不会继续执行 AI 请求。

## 一次部署，玩家扫码

没有额外服务器预算时，可以先使用仓库根目录的 `render.yaml` 部署 Free Web Service，详见 [Render 免费部署教程](music-render.md)。登录面板会先等待服务唤醒；免费模式重启后需要重新扫码，账号设置中有对应提示。Render 服务实际创建并验证前，内置地址继续留空。

部署者在仓库根目录运行 `node services/music-gateway/launch.mjs`，脚本自动检查并安装固定版本引擎、首次创建私密配置并启动服务。线上还需配置自己服务器的 HTTPS；Pages 页面无法运行 Node 或自动部署云服务器。已有配置不会被覆盖。

部署者在 `js/modules/music_config.js` 填好公开 HTTPS 服务地址并更新网页后，玩家直接点网易云/QQ音乐的“扫码登录” → 用对应官方 App 授权 → 账号“歌单” → “导入到资料库”。不需要玩家填写地址或运行服务脚本。自定义服务可在「更换音乐服务」填写；留空并保存恢复内置地址。

当前尚未部署公网音乐服务，内置地址留空；界面会显示“音乐登录服务尚未部署”，不会请求示例地址。部署完成后只需修改这一个公开配置文件，并更新 `index.html` 中它的缓存版本。文件内不放 cookie、Token、密码或 vault 密钥。内置地址不会随玩家偏好设置写入备份，保留的自定义地址始终优先。脚本细节见 `services/music-gateway/README.md`。
