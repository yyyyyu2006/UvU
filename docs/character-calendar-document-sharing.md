# 角色日历与文件分享

## 日历
打开“日历与天气”，顶部选择“我的日历”或具体角色。选择角色后，“设置”编辑的是该角色的位置与异地模式；切换到其他聊天不会改变正在查看的角色。角色未配置位置时会提示去设置，不会把用户的位置冒充角色位置。日历选择不会自动启用 AI 环境感知。

## 分享文件
聊天扩展面板 → 文件 → 选择接收角色 → 选择文件 → 核对或编辑正文 → 发送文件。随后在聊天中告诉角色阅读要求，例如“帮我改成周日，并把修改后的文件发回来”，再照常点击回复键。

- 可读取 TXT、Markdown、DOCX、文字 PDF、CSV、TSV、XLSX、XLS；每份最多 5MB、100000 字符。
- PDF 最多 200 页；扫描件需要先 OCR，加密文件需要先解密。Word、PDF 复杂排版和图片不进入文字编辑流程。
- 表格最多 30 个工作表，每表最多 5000 行、100 列；读取已有单元格值，不执行公式或宏，不保留复杂排版。
- 原件保存在本机聊天数据中，可从卡片“下载原件”。发送前编辑正文时仍保留原件，角色看到的是编辑后的文字。
- 点击文件卡片可查看、导出文本或 DOCX，并编辑发送新副本。原消息不会被覆盖。模型改稿也保存成新的文件消息，并关联来源。
- PDF 改稿回传 DOCX 或 TXT，表格改稿回传 CSV/TSV；不承诺回传原格式的排版、公式或多工作表结构。

文件在本机解析，正文仅在后续调用当前聊天 API 时进入模型上下文，原件二进制不发送给模型。只处理本轮历史范围内最近 8 份文件，正文总预算 32000 字符；超出时标明截取，并拒绝把截断文件的改稿当作完整版本。需要全文改稿时，请拆分再分享。历史范围仍受原聊天记忆设置和上下文开关约束。

本功能沿用现有聊天 API，不额外配置文件专用 API。模型仍需支持并遵循文件回传协议；响应不完整、来源不符等情况会明确报错，不执行其中的操作。真实模型的阅读与编辑质量需由用户核对。

## 兼容边界与验证
未分享文件时，新模块不附加提示词或改写请求历史。1900 基线的原提示词正文、默认世界书位置和普通回复解析保留；有分享文件的请求才附加文件资料和回传规则。新文件消息随聊天与存档备份，导入时校验正文和原件字段。旧版本未提供文件卡片或文件上下文模块时，只能保证原有普通消息机制，不保证识别新文件卡片。

验证包含 1900 提示词/请求相等性、OpenAI 兼容/Gemini 请求及流式参数传递，整页本地模拟接口回传、定向发送、切换角色、过期天气结果丢弃、保存失败回滚、完整英文/中文 PDF、DOCX、XLS/XLSX 等解析、特殊标签文字、文件单独回传、备份校验和 320/390/768 像素布局。没有使用真实密钥或付费模型。iOS/安卓真机及用户实际模型仍需验收。

依赖版本、许可证与来源见 `js/vendor/document-libraries.json`。PDF.js 与 SheetJS 资源随仓库部署，按需加载；不会存放玩家数据到 GitHub。
