# 教程与 GitHub 备份

教程的本机完整备份和 GitHub 备份都使用存储页的校验器、字体与媒体导出器、向量 portable export、有界解析器和同一 Dexie 事务。恢复失败不替换 RAM，不提前清表；文件未提供的分类保留。教程完整恢复会替换文件中提供的角色、群、世界书、表情与字体快照，存储页分类导入仍保留既有的分类合并规则。旧分块备份只有在所有引用块完整且有效时才恢复。所有入口导入 MCP 均关闭开关与授权，连接需重新确认。

本机完整备份包含 API 密钥。存储页可选择“分享迁移包”，该选项强制移除受支持 API 设置的凭据，聊天仍按选择导出。GitHub 默认移除密钥，可在界面明确启用；只允许私有仓库上传完整备份。压缩不是加密；本次没有新增密码加密格式。GitHub Token 保存在浏览器配置中，不是应用 db 备份内容。

云端路径是前缀，每次产生独立的带时间和随机后缀快照，不覆盖上一份。可指定分支，留空跟随仓库默认分支。当前设备记录最后成功路径；其他设备通过指定前缀目录发现快照，目录达到 GitHub 1000 项列表边界时拒绝猜测最新文件，请下载选定快照后本机导入。旧自定义固定文件名仍可发现。不会无条件重试冲突或 PUT 超时；PUT 取消或超时后应先核对远端结果。

自动备份仅在网页前台检查，约每分钟检查到期，回到前台会补检。关闭、系统挂起或浏览器后台节流时不保证定时。失败后至少间隔五分钟再自动尝试；多个入口共享一个进行中的任务。配置损坏或无法写入 localStorage 时保留普通功能，并提示重新填写或检查权限。

云端响应包含超时、取消与字节上限，下载最多 64 MiB、上传包最多 48 MiB。恢复仍受共享解析器限制：worker 解压后最多 512 MiB；无 worker 的兼容路径最多 8 MiB。无法启动 worker 时会在写入前报错。浏览器不支持压缩时自动保存 JSON；不支持解压时提示回原设备导出 JSON。取消仅适用于提交前，原子事务开始后请保持页面打开。

完整导出先分离应用 JSON 与相册引用，再异步读取字体、媒体表与向量，manifest 记录捕获时间与范围；独立数据库之间尚无统一 revision，不承诺跨标签或并发写入下的全库同刻快照。外链图片、字体和小组件只保留引用，不下载外部资源。
