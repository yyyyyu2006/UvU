# 桌宠外形、圆角与音乐默认图标缩放

本批基于 695a4ed，按用户新需求局部实现；先交 test，main 等本批确认。

## 可见行为

- 桌宠设置提供原图、正方形、4:3 长方形、圆形。
- 原图保留旧版 contain 显示；其他外形居中裁切图片。圆角可在 0–50% 调整；圆形固定 50%，滑块也显示 50，切回其他外形恢复此前自定义圆角。
- 可开关背景并用系统颜色选择器选色；关闭时背景透明。仅实时预览，点击保存才持久化，取消不改已保存外观。
- 老设置没有新增字段时维持原图、无圆角和透明背景；图片、位置、大小、API 设置保留。拖动保存继续保留外观字段。
- 长方形按实际宽高计算移动范围和菜单位置；最小点击范围仍为 44px。原有延迟保存、失败回退、跨标签设置冲突保护保留。
- 音乐默认图案缩至此前 80%，透明画布和 54px 图标按钮大小保持原实现；自定义图标仍优先。仅调整默认资源及缓存版本，不改其他图标或音乐布局。

## 指南与边界

本轮 Modern Web Guidance 检索并完整读取 overflow-clipping-control 和 css。按 “Fallback to overflow: hidden as the base experience” 使用通用圆角裁切，未依赖受限的 overflow-clip-margin；按 “DO NOT use global resets” 限定桌宠外观及设置选择器。图片本身与圆角共享一个裁切区域，阴影位于该区域外侧，焦点框留在按钮上。

未新增第三方 UI 库，未改提示词、历史范围、回复顺序、原版/个人美化、音乐内部页面、ID卡或已发送卡片。用户手机/Safari、软键盘、个人真实主题和真实 API 未新增实测；未执行全仓逐行审查或新安全扫描。

推送、部署与用户验收分别核验；源码回退使用正常 Git revert，保留个人图片/自定义图标和 API 预设，不清数据库。
