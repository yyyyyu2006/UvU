# 新增面板黑白重排实施计划

**Goal:** 落实已确认 v4 图册的新增面板布局。
**Architecture:** 复用已有 panel_layout 装饰器，仅移动现有节点；新增带范围标记的样式层，不接管业务事件、表单保存或请求。
**Spec:** 用户确认的 uvu-monochrome-v4 图册及 scope.json。

## 保护边界
- 1900 原版 CSS、基础提示词、回复流程不改。
- 音乐 App、播放器、歌单、一起听及音乐卡片不改。
- 导出 PNG 的 ID Card 渲染代码、作者、签名与透明圆角不改；只整理导出设置。
- 共享页面只标记二改新增的节点。真实状态、错误、权限说明不能用演示内容替代。
