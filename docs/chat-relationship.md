# 好友关系与单条消息删除

私聊进入「聊天设置 → 功能 → 好友关系 / 拉黑 / 验证」。支持我拉黑或删除角色，也可模拟角色拉黑或删除我。旧角色缺少新字段时仍按正常好友处理，群聊保持原行为。

删除好友保留角色数据、聊天和记忆，只从我的好友列表移除；原聊天列表仍可进入，方便发送验证和恢复。角色主动删除我时，我的好友列表仍保留角色。聊天列表原来的「删除聊天」是另一个旧入口，会删除整个角色或群聊，并非这里的解除好友关系。

对方拉黑后，发送的文字、表情、图片、语音等保留在界面，显示红色感叹号与「消息已发出，但被对方拒收了。」；对方删除我时显示朋友验证提示，可发送验证内容，再手动模拟对方通过。也支持模拟对方请求重新添加、由我通过。自己的拉黑需要自己解除，添加好友不会顺带解除拉黑。

被拒收的消息永久标记为未送达，不会因为解除拉黑或重新开启上下文而自动补发。这些消息不进入聊天、日记总结或向量记忆；拒收消息不能作为新引用。通话、主动获取回复、后台回复和重回也检查私聊好友关系。好友状态变化期间到达的旧回复丢弃。

好友关系属于当前存档剧情，切换存档各自独立；备份归在「聊天记录」，单独分享「角色设定」不会携带黑名单剧情。

恢复规则默认手动，可选定时恢复（1–43200 分钟），或独立 API 条件判断。定时恢复解除对方的拉黑和删除状态，不解除我自己的拉黑。应用查看当前聊天时约每分钟检查一次，打开聊天或点击获取回复时也会检查；关闭应用期间不承诺准时执行，重新打开后处理已到期规则。

条件判断使用日记路由 API，未配置副 API 路由时沿用主 API。此功能明确选择后才启用，自动检查最多每五分钟一次，只在应用前台查看该私聊时运行，另有「现在检查恢复条件」。它独立发送条件、角色性格、最近已送达剧情、经过时间和朋友验证内容，不改写原来的聊天／思维链／总结提示词。最多取最近20条符合要求的历史，剧情最多12000字符、人设最多8000字符；无法承诺模型完全准确，要求高时使用手动恢复。API失败、无效结果、存档切换或状态变化不会恢复关系。

长按消息的「删除」仅删除当前消息，「多选」继续提供批量删除和转发。新增单条删除和好友状态保存具有失败回滚，存档切换时不影响新存档。

开发验证：运行 npm test。浏览器验证使用独立本地测试数据库，检查完整应用初始化、原生 IndexedDB 保存与刷新恢复、拒收提示、双向好友验证、单条删除及320／375／412宽度下弹窗滚动。尚未覆盖 iOS／安卓真机及用户的每一套自定义美化。
