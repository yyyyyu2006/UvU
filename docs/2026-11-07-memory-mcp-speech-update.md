# 向量记忆、MCP 与语音更新

本次细化三个二改模块。原聊天提示词、世界书位置、聊天历史选择和主回复请求流程未作改写。新增高级选项默认关闭，需自行保存启用。

## 向量记忆

- 正文标签和排除标签可配置，提供清洗预览；不会改动聊天原文。
- 可按消息编号保持来源稳定，删除前面的无关楼层时减少重复建库。
- “续建索引”只建立文档索引，不再为示例问题调用一次查询嵌入；支持暂停和继续。
- 可开启“聊天时只检索已有索引”，避免首次大库建设阻塞回复准备。
- 可配置分块大小、重叠，以及每块、每批和召回上下文的 Token 估算预算。
- 可开启短时查询/结果缓存、关键词与向量融合、来源去重、专用重排最低分过滤。
- 可选独立查询整理 API，最多整理两个检索问题；失败沿用原查询。
- 可选独立增量索引库，按角色、存档和模型隔离；完整或聊天分类备份仍可带上有效索引。

操作：打开聊天的“向量记忆”设置 → 配置嵌入接口 → 保存 → 到记忆库“更多”中续建索引。先用正文清洗预览检查预设标签，再按需要逐项开启高级选项。更换标签、分块或模型后再续建。独立索引保留旧数据和运行时兼容镜像；普通聊天保存仍可能保存该镜像。

Token 是本机估算，不等同供应商账单。分块重叠、查询整理和重排可能增加用量；批量请求主要减少网络往返。

## MCP

- 单个服务失败时保留其他服务的有效结果。
- 校验工具输入与结构化输出；大 JSON 缩减后仍保持合法结构。
- 过期会话只对明确标为只读的请求恢复一次，写入操作不会自动重发。
- 缓存按角色和存档隔离，支持有限并发、工具目录和规划时间预算。
- 支持公开客户端 OAuth PKCE 登录和刷新；授权凭据不进入普通配置备份。
- 支持资源、提示模板的手动预览、复制、导出，不自动替换提示词。
- 普通嵌套对象提供表单；复杂数组、引用和组合结构保留 JSON 编辑。
- 工具结果可留在预览中，或明确选择“供下轮参考”；不会自动存成长期记忆。

操作：MCP 服务中心 → 新建服务并测试 → 按服务要求填 Token 或登录 → 给指定角色授权工具 → 测试调用 → 需要时选择“供下轮参考”。自动规划另外使用其独立 API 设置。

OAuth 需要服务允许浏览器跨域访问，并预先登记公开客户端 ID 与回调地址；不能让所有第三方服务免配置直接登录。具体步骤已写入应用内教程。

## MiniMax 语音与导演

- 按模型能力发送情绪参数，增加区域提示、响应大小和音频解码检查。
- 支持读取、搜索、收藏音色，为角色设置独立音色、导演风格和读音词典。
- 语音详情可查看导演结果、普通播放、重试导演，或手动调整支持的情绪与语速。
- 导演控制只影响合成参数，不写入聊天正文，不把控制标签当正文朗读。
- 可选流式播放、长语音分段、限额和过期时间可配置的本机音频缓存。
- 不支持流式解码时，使用同次请求已收到的完整 MP3 回退，不额外合成一遍。
- 分别显示服务返回的语音计费字符和导演 Token；缓存复用显示零新增用量，未返回的字段标为未知。

操作：API 应用 → MiniMax 角色语音 → 配好接口并试听 → “音色与表达”选择默认设置或具体角色 → 保存。旧聊天设置中的角色 Voice ID 仍有优先级。流式、分段和持久缓存均需手动开启；音频缓存是可清理的本机缓存，不随普通备份导出。
